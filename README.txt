I SAW. — editable photography portfolio

WHAT'S INCLUDED
- index.html: page content and image filenames
- style.css: colours, typography, spacing and layout
- script.js: optional interactions
- images/: replace the placeholder image files with your own photographs

HOW TO ADD YOUR PHOTOGRAPHS
1. Put your cover photograph in images/cover.jpg
2. Add your gallery photos as images/photo-01.jpg, photo-02.jpg, photo-03.jpg and photo-04.jpg
3. Keep the same filenames, or edit the matching image paths in index.html.
4. You can add more gallery items by copying one <a class="gallery-item"> block in index.html.

HOW TO CHANGE YOUR EMAIL
Open index.html and replace hello@example.com with your email address.

PUBLISH FOR FREE WITH GITHUB PAGES
1. Create/sign in to your own GitHub account.
2. Create a repository named exactly: YOURUSERNAME.github.io
3. Upload the contents of this folder (not the outer folder) to that repository.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Your site will appear at https://YOURUSERNAME.github.io after GitHub finishes publishing.

WHO CAN EDIT?
Only you (and anyone you explicitly grant repository access to) can change the website through your GitHub account.
Visitors can view the public website but cannot edit it. Keep your GitHub password private and enable two-factor authentication.

NOTES
- GitHub Pages is free for public repositories. The website is public, and the source files are visible, but visitors cannot edit your site just by visiting it.
- The site has no website-builder branding or watermark.
- A custom .com domain is optional and costs extra.
- The fonts load from Google Fonts; if offline, fallback fonts are used.
